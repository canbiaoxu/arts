# SKK

This project encapsulates commonly used functions in Python development to help you develop applications more efficiently.

## Project Links

- [Contributors List](https://github.com/canbiaoxu/skk/graphs/contributors)
- [GitHub](https://github.com/canbiaoxu/skk)

## Installation

```bash
pip install https://github.com/canbiaoxu/skk/archive/refs/heads/main.zip
```

## Feature Categories

### AI

* [micro_cognition -- Micro-paradigm based AI reasoning model](https://github.com/canbiaoxu/skk/tree/main/skk/micro_cognition)
* [ollama -- Deploy deepseek local version on Windows platform and call it with Python](https://github.com/canbiaoxu/skk/tree/main/skk/ollama)
* [openai -- Access ChatGPT](https://github.com/canbiaoxu/skk/tree/main/skk/openai)

### Database

* [mysql -- Access MySQL database](https://github.com/canbiaoxu/skk/tree/main/skk/mysql)
* [mongo -- Access MongoDB database](https://github.com/canbiaoxu/skk/tree/main/skk/mongo)
* [postgre -- Access PostgreSQL database](https://github.com/canbiaoxu/skk/tree/main/skk/postgre)
* [objdb -- Access ObjDB database](https://github.com/canbiaoxu/skk/tree/main/skk/objdb)
